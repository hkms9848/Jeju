# 🍊 제주도 여행 플래너

## 실행
`index.html`을 브라우저로 열거나 GitHub Pages에 `index.html`, `style.css`, `app.js`를 업로드하세요. 지도와 도로 경로 조회에는 인터넷이 필요합니다. 로컬 데이터는 브라우저 localStorage에 저장됩니다.

## 중요: 제공 범위
이 버전은 **로컬 데모**입니다. 링크를 공유해도 다른 사람의 일정이 동기화되지 않습니다. 로그인, Supabase Auth, Realtime, RLS, 참여자 권한, 공동 편집, 충돌 해결, 서버 변경 이력 및 버전 복구는 구현되지 않았습니다. 항공편/숙소/렌터카는 현재 이름과 자유 형식 상세 정보로 저장합니다. 비용은 지출 합계만 지원하며 공동 정산은 미구현입니다. 장소 검색/지도 클릭 좌표 선택/구간별 거리도 미구현입니다.

## 무료 API 주의
OpenStreetMap 공개 타일은 이용 정책 및 식별 정책을 준수해야 합니다. OSRM 공개 데모 서버는 운영 서비스용으로 보장되지 않으며 호출 제한과 장애가 발생할 수 있습니다. 실패 시 직선 경로(도로 거리/시간 아님)를 표시합니다. 상용 서비스는 자체 호스팅 또는 정책에 맞는 제공업체가 필요합니다.

## 공동 편집 확장 설계
Supabase 프로젝트 생성 후 Auth 인증, trips, trip_members, places, expenses, packing, notes 테이블과 RLS를 구축해야 합니다. trip_members에 owner/editor/viewer 권한을 저장하고, 모든 쓰기 정책에서 인증 사용자 및 여행별 권한을 검증합니다. 여행 초대는 추측 불가능한 일회용 토큰을 서버에서 검증해야 합니다. Realtime Postgres Changes를 구독하고 각 레코드에 revision 및 updated_at을 두어 낙관적 잠금 충돌을 처리하세요. 공개 프론트엔드에는 anon/publishable key만 사용하고 service_role 키를 절대 넣지 마세요. 브라우저 공유 링크만으로 권한을 부여하지 마세요.

## 테스트
시작/종료 날짜 변경, 탭 자동 생성, 기간 축소 시 보관/이동/취소, 장소 추가 및 순서 변경, 지도 마커/경로 재조회, JSON 백업/복원, 새로고침 후 저장 상태를 점검하세요. Supabase 공동 편집 테스트는 이 버전에 적용되지 않습니다.
